# How v2.13 "Home Again" was built

Every image is a capture from the real game while it was being built, in order.

**This round:** the [design direction](../../../DESIGN_DIRECTION.md)'s ending, finally played rather than described: *"When Sam returns home, the model is still imperfect and the degree is still a decision, not magically solved. They repair one corner, answer their friend, and take a manageable next step."* Chapter 13 happens on campus, with a new classmate (Ren), a new interior (the engineering studio), and a small, gentle version of the bridge puzzle.

## 4. The puzzle: rebuild the model bridge, together

| | | | |
|---|---|---|---|
| ![](10_model_bridge_empty.jpg) | ![](11_model_bridge_squares_only.jpg) | ![](12_model_bridge_triangles.jpg) | ![](13_model_bridge_holds.jpg) |
| A smaller truss than the Amberleaf bridge: 6 x 2 dots, 25 scraps. | Squares only (it folds as soon as the cart rolls on). | Triangles, diagonals leaning down toward the middle so they're pulled, not squished. | It holds, with room to spare. The lesson: *it isn't the strongest bridge in the room, it's the best one you two have made, and you can say why every stick is where it is.* |

Tuning: at a cart weight of 6 the plain triangle design holds (0.90 of capacity), so it's deliberately forgiving. It's a cozy chapter.
