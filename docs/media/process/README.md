# Process: how each version was built

<a href="https://normansrule.github.io/cardboard-kingdom/play.html"><img src="../buttons/play.svg" alt="Play Cardboard Kingdom in your browser" height="64"></a> <a href="https://normansrule.github.io/cardboard-kingdom/versions.html"><img src="../buttons/versions.svg" alt="Play any earlier version" height="64"></a>

From v2.9 on, every round keeps a folder of in-progress captures (before shots, blockouts, first passes, what changed and why, and the final result) so you can see the process, not just the result.
